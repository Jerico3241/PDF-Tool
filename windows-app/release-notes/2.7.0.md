## PDF Tool 2.7.0 – Next Generation UI

PDF Tool besitzt jetzt eine **vollständig neue Oberfläche auf Basis von Qt 6** (PySide6, Qt Quick/QML).
Alle Funktionen aus 2.6.1 bleiben erhalten – Vertragsübersichten mit Stapel, Vorschau, optionaler
Kundenakte und Vertragsvergleich sowie „PDF reparieren“ mit erweiterter Wiederherstellung.

### Highlights

- neue, moderne Benutzeroberfläche im Stil von Windows 11
- deutlich flüssigere Navigation mit sanften Seitenübergängen
- echte Animationen – auch für Menüs und Dialoge
- bessere Skalierung auf hochauflösenden Bildschirmen (100–200 %)
- effizientere Listen im Stapel, in der Kundenliste und im Vertragsvergleich
- überarbeitete Vertragsübersichten und ein neues Frontend für „PDF reparieren“
- vollständig erhaltene bestehende Funktionen

### Neue Oberfläche

PDF Tool wurde vollständig von Tkinter auf **PySide6 und Qt Quick/QML** umgestellt. Die Fachlogik
(Excel-Prüfung, PDF-Erstellung, Kundenakte, Stapel, Vertragsvergleich, PDF-Reparatur) ist
unverändert; eine eigene Qt-Schicht verbindet sie mit der neuen Oberfläche. Die App startet ohne
weißes oder halb aufgebautes Fenster und zeigt zuerst die Startseite mit allen Werkzeugen.

### Modernes Design

Komplett überarbeitete, an Windows 11 orientierte Oberfläche: Karten, Navigationsleiste mit
Auswahlindikator, Hinweisleisten, Schalter, Auswahllisten und Dialoge folgen einem einheitlichen
Design-System (Farben, Abstände, Radien, Schrift Segoe UI Variable). Hell, Dunkel und „Wie Windows“
sowie die Windows-Akzentfarbe wirken sofort; Mica, wo Windows es unterstützt.

### Animationen

Neue Animationen für Navigation und Seitenwechsel, Menüs, Tooltips, Dialoge, aufklappende Bereiche
(Accordions), Hinweisleisten (InfoBars), Schaltflächen, Schalter (Toggle Switches), Eingabefelder und
Statuswechsel. Unter **Einstellungen → Animationen**: „Vollständig“, „Reduziert“ (nur kurze
Überblendungen) oder „Aus“ – wirkt sofort. Ist in Windows „Animationseffekte“ ausgeschaltet, gilt
mindestens „Reduziert“.

### Performance

Neue Model/View-Architektur: Listen ändern nur die betroffenen Zeilen statt neu aufzubauen und
bleiben auch mit Hunderten Kundenakten oder großen Stapeln flüssig. Seiten entstehen einmal und
werden danach nur noch gezeigt; Arbeit wie Excel-Prüfung, PDF-Erzeugung, Vorschau und Reparatur
läuft im Hintergrund, die Oberfläche bleibt bedienbar.

### High DPI

Verbesserte Darstellung auf hochauflösenden Displays: Text, Symbole (Fluent UI System Icons als
Vektorgrafik) und Vorschau sind bei jeder Skalierung scharf.

### Bestehende Funktionen

Alle Funktionen aus 2.6.1 wurden übernommen: Excel-Prüfung mit Fettschrift, Vorlagen, Textbausteine,
formatierte Kopf- und Fußzeilen mit Rückgängig/Wiederholen, Zyklus-Regeln, Live-Vorschau (jetzt mit
„Ganze Seite“), Stapelverarbeitung, optionale Kundenakte (weiterhin standardmäßig aus),
Vertragsvergleich, PDF reparieren (Analyse, Diagnose, Passwort, Signaturwarnung, teilweise
Wiederherstellung, Rettungsmodus, Rekonstruktion der Dokumentstruktur), Tastenkürzel (Strg+1 … 4,
Strg+Enter, Strg+O, Strg+F, F1) und Drag & Drop.

### Keine manuelle Migration nötig

Bestehende **Einstellungen, Kunden, Vorlagen, Regeln und Vertragsstände** werden weiterverwendet.
Das Update verändert keine Benutzerdaten; die Kundenakte bleibt so eingestellt, wie sie war.

### Installation

Das Setup `PDF-Tool-Setup-2.7.0.exe` enthält Python, Qt/PySide6 und alle erforderlichen Pakete –
**keine separate Installation nötig**. Installation ohne Administratorrechte, Windows 10 und 11
(64 Bit). Ein vorhandenes PDF Tool wird aktualisiert (dieselbe App-ID, kein zweiter Eintrag unter
„Installierte Apps“); die frühere Tk-Oberfläche wird dabei vollständig ersetzt. Updates von 2.6.1,
2.6.0, 2.5, 2.4, 2.3 und vom Übersichten-Ersteller (bis 2.2) werden unterstützt.

Die Datei `.sha256` enthält die Prüfsumme des Setups. Das Setup ist nicht signiert. Beim ersten
Start kann Windows SmartScreen einen Hinweis zeigen („Weitere Informationen“ → „Trotzdem ausführen“).

**Alle Dateien werden lokal verarbeitet** – keine Cloud, keine Uploads.
