## PDF Tool 4.0 Beta 4 – Outlook, Taskleiste, Symbol

**Beta-Version zum Testen.** Sie erscheint nur mit „Beta-Versionen erhalten“ (Einstellungen →
Updates) und ist noch nicht freigegeben. Die stabile Version bleibt 3.2.0. Diese Beta bringt keine neuen
Funktionen.

Alle Funktionen von 3.2.0 und den Betas 1 bis 3 bleiben erhalten.

### PDFs aus Outlook öffnen

- Doppelklick auf einen PDF-Anhang im klassischen und im neuen Outlook tat nichts bzw. meldete „Auf das
  angegebene Gerät bzw. den Pfad oder die Datei kann nicht zugegriffen werden“. Ursache: Eine Regel von Microsoft
  Defender („Erstellen von untergeordneten Prozessen nur für Office-Kommunikationsanwendungen blockieren“) verbietet
  Outlook, Programme direkt zu starten. PDF-Dateien öffnet Windows jetzt auf dem regulären Weg der Windows-Shell
  für Dateizuordnungen: Windows selbst startet PDF Tool und übergibt die Datei (wie bei Apps aus dem Microsoft
  Store). Eine Ausnahme in Defender ist dafür nicht nötig.
- Lief PDF Tool schon (etwa im Hintergrund), endete das Startprogramm, bevor die Datei an das laufende PDF Tool
  übergeben war. Es wartet jetzt, bis die Übergabe erledigt ist.
- Neu im Support-Paket: ein Übergabe-Protokoll. Es zeigt, ob ein Start aus Outlook ankommt, ob der Anhang
  gesichert und übergeben wurde – ohne Dateinamen.

### Taskleiste und Symbol

- Rechtsklick auf PDF Tool in der Taskleiste zeigt „PDF Tool“ mit dem eigenen Symbol statt „Python“.
- Das App-Symbol ist in Taskleiste, Titelleiste und Explorer (16–24 Pixel) pixelgenau gezeichnet und scharf;
  „PDF“ ist lesbar.
- PDF-Dateien in der Sprungliste („Zuletzt verwendet“) und im Explorer zeigten noch das alte Symbol, weil Windows
  es zwischengespeichert hatte. Sie zeigen jetzt das neue.

### Updates

- Das Update von Beta 3 auf Beta 4 läuft mit einem Klick, ohne Setup-Assistent. Getestet unter Windows: Beta 3
  läuft im Hintergrund, das Update installiert still und startet PDF Tool neu.
