## Neu in Version 2.3.0

**Aus dem Übersichten-Ersteller wird PDF Tool** – eine Windows-App mit Werkzeugen für PDF-Dateien.

- **Startseite mit Werkzeugen:** Nach dem Start zeigt PDF Tool alle Werkzeuge als Karten. Die Navigation führt zu *Start*, den *Tools* (*Vertragsübersichten*, *PDF reparieren*) und den *Einstellungen*. Tastenkürzel Strg+1 bis Strg+4; eine Datei kann direkt in das Fenster gezogen werden – eine PDF öffnet „PDF reparieren“, eine Excel-Liste „Vertragsübersichten“.
- **Vertragsübersichten als eigenes Werkzeug:** alle bisherigen Funktionen bleiben erhalten – Excel-Analyse, Excel-Fettschrift, formatierte Kopf- und Fußzeilen, Standard-Fußzeile, Vorlagen, Textbausteine, Zyklus-Regeln, Kundenverlauf, Hoch- und Querformat. „Übersicht erstellen“ und „Darstellung“ wechseln über eine Umschaltleiste; „Verlauf löschen“ steht jetzt unter „Darstellung“.
- **Neues Werkzeug „PDF reparieren“:**
  - Analyse vor der Reparatur: Größe, Seiten, PDF-Version, Verschlüsselung, Querverweistabelle, Objekte, Trailer, Seitenbaum, Metadaten, Datenströme, Formulare, Anhänge und digitale Signaturen – mit einer klaren Einschätzung („Keine Fehler gefunden“, „Reparierbare Probleme erkannt“, „Schwer beschädigt“, „Keine Reparatur möglich“)
  - mehrstufige Reparatur mit zwei Engines (qpdf und PDFium); die geprüfte Ausgabe mit den meisten vollständigen Seiten wird verwendet
  - ehrliche Ergebnisse: repariert, teilweise wiederhergestellt („12 von 15 Seiten …“) oder nicht reparierbar; fehlende Bestandteile werden genannt
  - die Originaldatei wird nie verändert oder überschrieben; die neue Datei heißt `<Name>_repariert.pdf`
  - verschlüsselte PDFs mit dem richtigen Passwort – das Passwort wird nicht gespeichert, die Kopie bleibt geschützt
  - Rückfrage bei digital signierten PDFs; optionaler Rettungsmodus „Lesbare Seiten als neue PDF retten“ nur nach Bestätigung
  - Arbeit in einem eigenen Prozess: die Oberfläche bleibt bedienbar, „Abbrechen“ beendet den Vorgang wirklich, es bleiben keine Zwischendateien zurück
  - vollständig lokal – nichts wird hochgeladen
- **Neues App-Symbol** für Startmenü, Taskleiste, Setup und „Installierte Apps“.

## Update vom Übersichten-Ersteller

- Das Setup aktualisiert die vorhandene Installation – unter „Installierte Apps“ steht danach nur noch **PDF Tool**, es entsteht kein zweiter Eintrag.
- Programmdateien ziehen nach `%LOCALAPPDATA%\PDF-Tool` um; der alte Programmordner und die alten Verknüpfungen werden entfernt. Eine an die Taskleiste angeheftete alte Verknüpfung bitte lösen und PDF Tool neu anheften.
- Beim ersten Start übernimmt PDF Tool Einstellungen, Vorlagen, Textbausteine, Zyklus-Regeln und den Kundenverlauf aus `%APPDATA%\Uebersichten-Ersteller` nach `%APPDATA%\PDF-Tool` – mit Sicherung (`migration-backup-<Version>.zip`) und Prüfung jeder Datei. Der alte Datenordner bleibt unverändert erhalten.

## Installation

Das Setup `PDF-Tool-Setup-2.3.0.exe` enthält Python und alle erforderlichen Pakete, auch die PDF-Engines – **keine separate Installation von Python, qpdf, Ghostscript oder anderen Programmen nötig**. Installation ohne Administratorrechte, Windows 10 und 11 (64 Bit).

Die Datei `.sha256` enthält die Prüfsumme des Setups. Das Setup ist nicht signiert; beim ersten Start kann Windows SmartScreen einen Hinweis zeigen („Weitere Informationen“ → „Trotzdem ausführen“).

## Hinweise

- Nicht jede beschädigte PDF lässt sich vollständig wiederherstellen. Teilweise gerettete Dateien werden deutlich gekennzeichnet.
- Eine Reparatur kann digitale Signaturen ungültig machen; die App fragt vorher nach.
- Die Lizenzen der enthaltenen Bibliotheken stehen in `THIRD_PARTY_LICENSES.md`.
