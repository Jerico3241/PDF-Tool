## PDF Tool 4.0 Beta 7 – Updates von selbst, aufgeräumte Leiste

**Beta-Version zum Testen.** Sie erscheint nur mit „Beta-Versionen erhalten“ (Einstellungen →
Updates) und ist noch nicht freigegeben. Die stabile Version bleibt 3.2.0.

Alle Funktionen von 3.2.0 und den Betas 1 bis 6 bleiben erhalten.

### Updates

- PDF Tool sucht bei jedem Start nach Updates und installiert ein gefundenes Update selbst. Danach startet es neu
  und öffnet die PDFs wieder, die vorher offen waren.
- Hat ein Dokument ungespeicherte Änderungen oder läuft noch eine Verarbeitung, wartet die Installation. Es geht nie
  etwas verloren.
- Abschaltbar unter Einstellungen → Updates → „Updates automatisch installieren“. Dann sucht PDF Tool nur und bietet
  „Jetzt installieren“ an.
- In den Einstellungen wird „Nach Updates suchen“ nach einem Fund zu „Jetzt installieren“. Die Neuerungen der neuen
  Version stehen direkt darunter. Die Hinweisleiste über den Seiten gibt es nicht mehr.

### Leiste oben

- Das Menü ≡ ist weg – jeder Eintrag hatte schon einen eigenen Knopf.
- „?“ öffnet das Hilfe-Menü: Kurzanleitung, Tastenkürzel, „Neu in dieser Version“ und „Über PDF Tool“.
- Das Zahnrad öffnet die Einstellungen ohne eigenen Tab. Solange sie offen sind, ist das Zahnrad markiert.

### Behoben

- Stapel-Aktionen: Beim Anklicken eines Kästchens wurde kurz ein anderes grau, und das Kästchen unter der Maus wurde
  nicht hervorgehoben.

### Updates

- Das Update von Beta 6 auf Beta 7 läuft mit einem Klick, ohne Setup-Assistent.
