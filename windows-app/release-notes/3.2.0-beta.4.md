## PDF Tool 3.2.0 Beta 4 – Im Hintergrund bereithalten

**Beta-Version zum Testen.** Sie erscheint nur mit „Beta-Versionen erhalten“ (Einstellungen →
Updates) und ist noch nicht freigegeben. Die stabile Version 3.2.0 folgt erst nach dem Test.

Alle Funktionen von 3.2.0-beta.1 bis 3.2.0-beta.3 bleiben erhalten.

### Schneller erster Start nach dem Hochfahren

Der erste Start nach dem Hochfahren des PCs dauerte lange, weil Windows Python, Qt und die Oberfläche erst
von der Festplatte laden muss; danach öffnete PDF Tool schnell. Neu unter **Einstellungen → Verhalten →
„Im Hintergrund bereithalten“** (standardmäßig an):

- PDF Tool startet mit Windows unsichtbar und baut sich dabei schon auf. Wird es danach geöffnet (Startmenü,
  Desktop, Doppelklick auf eine PDF), erscheint das Fenster der bereits laufenden App – ohne erneutes Laden.
- Das **Schließen-Kreuz** schließt nur das Fenster. Geöffnete PDFs werden wie beim Beenden geschlossen (mit
  der gewohnten Rückfrage bei ungespeicherten Änderungen); PDF Tool bleibt mit seinem Symbol im
  **Infobereich der Taskleiste** (rechts unten). Ein Klick darauf öffnet das Fenster wieder. Beim ersten Mal
  erklärt ein kurzer Hinweis, wo PDF Tool jetzt ist.
- **Ganz beenden:** Rechtsklick auf das Symbol im Infobereich → „Beenden“.
- Ausgeschaltet verhält sich PDF Tool wie bisher: kein Symbol, kein Start mit Windows, das Kreuz beendet.
- Updates, „Neu starten“ nach einer Wiederherstellung und das Abmelden von Windows beenden PDF Tool wie
  bisher ganz. Die Deinstallation entfernt auch den Eintrag unter „Start mit Windows“.

Ein weiterer Start gibt der laufenden App nur noch Bescheid und endet sofort – ohne Qt und die Oberfläche zu
laden. Im Hintergrund belegt PDF Tool Arbeitsspeicher wie ein geöffnetes, aber verstecktes Fenster.

### Update

Wer „Beta-Versionen erhalten“ eingeschaltet hat, erhält 3.2.0-beta.4 über Einstellungen → Updates – von
3.2.0-beta.3, 3.2.0-beta.2, 3.2.0-beta.1 und ebenso direkt von 3.1.0. Ohne den Schalter (Kanal „Stable“)
wird diese Beta nicht angeboten. Beim ersten Start trägt sich PDF Tool unter „Start mit Windows“ ein
(Task-Manager → Autostart-Apps: „PDF Tool“). Alle Einstellungen, Kundenakten, Vorlagen, Regelwerke und
Sicherungen bleiben erhalten.
