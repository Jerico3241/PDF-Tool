## PDF Tool 2.7.2 – In-App Updates

PDF Tool kann neue Versionen jetzt direkt innerhalb der Anwendung erkennen, herunterladen und
installieren – eine manuelle Suche auf GitHub ist nicht mehr nötig.

### Highlights

- **Integrierte Update-Prüfung:** unter Einstellungen → Updates mit „Nach Updates suchen“, der
  aktuellen Version und dem Zeitpunkt der letzten Prüfung.
- **Stable- und Beta-Kanal:** Stable ist der Standard und enthält nur freigegebene Versionen. Beta
  liefert zusätzlich Vorabversionen zum Testen – erst nach einer Rückfrage.
- **Automatische Hintergrundprüfung:** höchstens einmal täglich, erst nach dem Start – der
  Programmstart wartet nie auf das Internet. Ohne Internetverbindung arbeitet PDF Tool wie bisher.
- **Release Notes direkt in PDF Tool:** „Details“ zeigt Version, Kanal, Datum, Größe und die
  Neuerungen; Links öffnen sich erst nach einem Klick im Browser.
- **Downloadfortschritt:** z. B. „42,8 MB von 78,3 MB · 55 %“, jederzeit abbrechbar.
- **SHA-256-Verifikation:** Jedes heruntergeladene Setup wird mit der veröffentlichten Prüfsumme
  verglichen. Ohne passende Prüfsumme wird nichts installiert, die Datei wird gelöscht.
- **Sichere Installation über das bestehende Setup:** „Jetzt installieren“ beendet PDF Tool wie über
  das Schließen-Kreuz und startet danach das Setup – nie während einer laufenden Verarbeitung.

### Sicher und unter Ihrer Kontrolle

- Geprüft und informiert wird automatisch; heruntergeladen und installiert wird nur auf Ihren Klick.
- Updates kommen ausschließlich aus den Releases des offiziellen Repositories, nur über HTTPS.
- Die automatische Prüfung lässt sich unter Einstellungen → Updates ausschalten.
- Einstellungen, Kundenakten, Vertragsstände, Vorlagen, Regeln, Textbausteine und alle übrigen
  Daten bleiben bei einem Update unverändert erhalten.

### Update

Ein Update von 2.7.1 ersetzt nur die Programmdateien. Alle Einstellungen und Daten bleiben
unverändert. Der Update-Kanal ist danach „Stable“, die automatische Prüfung eingeschaltet.

### Installation

Das Setup `PDF-Tool-Setup-2.7.2.exe` enthält Python, Qt/PySide6 und alle erforderlichen Pakete –
**keine separate Installation nötig**. Installation ohne Administratorrechte, Windows 10 (ab Version
1809) und Windows 11 (64 Bit). Ein vorhandenes PDF Tool wird aktualisiert (dieselbe App-ID, kein
zweiter Eintrag unter „Installierte Apps“).

Die Datei `.sha256` enthält die Prüfsumme des Setups. Das Setup ist nicht signiert. Beim ersten
Start kann Windows SmartScreen einen Hinweis zeigen („Weitere Informationen“ → „Trotzdem ausführen“).

**Alle Dateien werden lokal verarbeitet** – keine Cloud, keine Uploads. Die Update-Prüfung fragt
nur bei GitHub nach neuen Versionen und überträgt dabei keine Dateien oder persönlichen Daten.
