## PDF Tool 4.0 Beta 1 – Stapel-Aktionen, PDF/A, PDF aus Bildern und Updates mit einem Klick

**Beta-Version zum Testen.** Sie erscheint nur mit „Beta-Versionen erhalten“ (Einstellungen →
Updates) und ist noch nicht freigegeben. Die stabile Version bleibt 3.2.0. Dies ist der erste Teil von
Version 4.0; weitere Betas folgen.

Alle Funktionen von 3.2.0 bleiben erhalten.

### Stapel-Aktionen (neu, Strg+6)

- Viele PDFs auf einmal bearbeiten: wählen oder hineinziehen, Aktionen ankreuzen, „Alle bearbeiten“.
- Aktionen: Text erkennen (OCR), Dokument bereinigen, Reduzieren, Wasserzeichen, Seitenzahlen, PDF
  verkleinern, Als PDF/A speichern, Kennwortschutz. Die Reihenfolge ist fest und immer richtig.
- Jede PDF wird als neue Datei gespeichert – neben dem Original oder in einem gemeinsamen Ordner, mit
  Zusatz am Namen (Standard „_bearbeitet“). Originale und vorhandene Dateien werden nie überschrieben.
- Fortschritt je Datei, „Abbrechen“ jederzeit. Kennwortgeschützte oder beschädigte PDFs halten den
  Durchlauf nicht an, sondern stehen mit Grund in der Liste.
- Gewählte Aktionen bleiben gespeichert; das Kennwort für den Kennwortschutz nie.

### Als PDF/A speichern (neu)

- Im Reader unter „Schützen“ → „Als PDF/A speichern …“ und als Schnellwerkzeug auf der Startseite.
- Speichert eine archivfähige Kopie nach PDF/A-2b: Fehlende Schriften werden aus Windows eingebettet,
  Farbprofil und Metadaten ergänzt; Skripte, Anhänge und ungültig werdende Signaturen entfernt. Die
  Meldung nennt, was geändert wurde. Das Original bleibt unverändert.

### PDF aus Bildern (neu)

- Fotos und Scans (JPG, PNG, TIFF, BMP, GIF, WebP) in das Fenster ziehen oder über das Schnellwerkzeug
  „PDF aus Bildern“ wählen.
- Im Explorer: Bilder markieren → Rechtsklick → „Senden an“ → „PDF Tool (Bilder zu PDF)“.
- Reihenfolge ändern, Seitengröße (wie das Bild, A4, Letter) und Rand wählen. Fotos werden ohne
  Qualitätsverlust übernommen, gedrehte Handyfotos stehen richtig herum, mehrseitige TIFFs ergeben
  mehrere Seiten. Die neue PDF öffnet sich gleich im Reader.

### Updates mit einem Klick

- PDF Tool lädt eine neue Version nach der automatischen Prüfung selbst herunter.
- „Jetzt installieren“ beendet PDF Tool, installiert ohne Setup-Assistent und startet PDF Tool danach
  wieder. Klappt die stille Installation nicht, erscheint das Setup wie bisher.
- Gilt ab dem Update von 4.0.0-beta.1 auf eine spätere Version. Das Update auf diese Beta selbst läuft noch
  einmal über den Setup-Assistenten, weil es die installierte Version startet.

### Einstellungen aufgeräumt

- Oben eine Leiste mit den Bereichen Allgemein, PDF Reader, KI-Assistent, Vertragsübersichten, Updates,
  Daten & Diagnose und Info. Jeder Bereich zeigt nur seine Einstellungen.

### Update

Wer „Beta-Versionen erhalten“ eingeschaltet hat, erhält 4.0.0-beta.1 über Einstellungen → Updates – von
3.2.0 und älteren Versionen. Ohne den Schalter (Kanal „Stable“) wird diese Beta nicht angeboten. Alle
Einstellungen, Kundenakten, Vorlagen, Regelwerke und Sicherungen bleiben erhalten.
