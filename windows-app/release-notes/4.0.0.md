## PDF Tool 4.0 – Stapel-Aktionen, Vergleichen, Scannen, Englisch

**Freigegebene Version** für alle – im Update-Kanal „Stable“ wie im Kanal „Beta“. Getestet als
Betas 4.0.0-beta.1 bis 4.0.0-beta.9; der Funktionsumfang entspricht 4.0.0-beta.9.

Für Anwender von 3.2 bringt 4.0 die Bearbeitung vieler PDFs auf einmal, eine neue Werkzeugleiste im Reader,
Vergleichen zweier Fassungen, Scannen, digitale Signaturen, Umwandeln in Word und Excel, eine englische
Oberfläche und Updates, die sich selbst installieren. Alle Funktionen von 3.2.0 bleiben erhalten. Alles läuft
lokal auf Ihrem PC.

### Stapel-Aktionen (Strg+6)

- Viele PDFs auf einmal bearbeiten: wählen oder hineinziehen, Aktionen ankreuzen, „Alle bearbeiten“.
- Aktionen: Text erkennen, Dokument bereinigen, Reduzieren, Wasserzeichen, Seitenzahlen, PDF verkleinern,
  Als PDF/A speichern, Kennwortschutz.
- Jede PDF wird als neue Datei gespeichert – neben dem Original oder in einem gemeinsamen Ordner. Originale und
  vorhandene Dateien werden nie überschrieben. Kennwortgeschützte oder beschädigte PDFs halten den Durchlauf nicht
  an, sondern stehen mit Grund in der Liste.

### PDF Reader

- **Neue Werkzeugleiste:** oben die Datei-Befehle (Öffnen, Speichern, Drucken, Per E-Mail senden, Rückgängig,
  Wiederholen), links neben dem Dokument die Schnellwerkzeuge (Auswählen, Kommentieren, Zeichnen, Text hinzufügen
  und bearbeiten, Objekt bearbeiten, Unterschreiben). „Alle Werkzeuge“ zeigt jedes Werkzeug mit Namen, in Gruppen.
- **Mit anderer Fassung vergleichen:** ältere Fassung links, neuere rechts; geänderter, neuer und entfernter Text
  ist farbig markiert, rechts die Liste aller Unterschiede.
- **Geteilte Ansicht:** zwei PDFs nebeneinander im selben Fenster, jedes mit eigener Seite und eigenem Zoom.
- **Präsentation (F5):** Vollbild, eine ganze Seite, weiter mit Pfeiltasten oder Leertaste, Esc beendet.
- **Vorlesen (Strg+Umschalt+Y):** mit den Stimmen von Windows, ohne Internet; das gesprochene Wort ist markiert.
- **Text über Seitengrenzen markieren**, kopieren, hervorheben und schwärzen.
- **Digitale Signatur:** PDFs mit einem Zertifikat aus dem Windows-Zertifikatspeicher oder einer .pfx-Datei
  signieren; vorhandene Signaturen werden geprüft (gültig, verändert, Zertifikat nicht vertrauenswürdig).
- **Umwandeln:** PDF in Word, Excel oder Text (Überschriften und Tabellen bleiben, in Excel echte Zahlen und
  Datumswerte); Word-, Excel- und PowerPoint-Dateien in PDF (dafür muss Microsoft Office installiert sein).
- **Als PDF/A speichern:** archivfähige Kopie nach PDF/A-2b, das Original bleibt unverändert.

### Scannen und Texterkennung

- Startseite → „Scannen“: jeder Scanner mit Windows-Treiber, Vorlagenglas oder Einzug, Farbe, Graustufen oder
  Schwarzweiß; die Seiten werden direkt eine PDF, auf Wunsch gleich durchsuchbar.
- Texterkennung in zehn Sprachen: Deutsch, Englisch, Französisch, Italienisch, Spanisch, Niederländisch,
  Portugiesisch, Polnisch, Türkisch und Russisch.
- PDF aus Bildern: Fotos und Scans in das Fenster ziehen oder im Explorer „Senden an“ → „PDF Tool (Bilder zu PDF)“.

### KI-Assistent (optional)

- Dokumente übersetzen – in neun Sprachen, als neues PDF.
- Fragen an mehrere PDFs oder einen ganzen Ordner; die Antwort nennt Datei und Seite, ein Klick öffnet die Stelle.
- Gescannte Seiten liest der Assistent über die Texterkennung. Alles bleibt auf diesem PC.

### Bedienung

- **Englische Oberfläche:** Einstellungen → Sprache (Deutsch, Englisch oder „Wie Windows“), ohne Neustart.
- **Eigene Tastenkürzel:** Übersicht mit Strg+F1 oder Einstellungen → Tastenkürzel; jedes Kürzel lässt sich
  ändern, entfernen oder zurücksetzen.
- **Leiste oben:** „?“ öffnet die Hilfe (Kurzanleitung, Tastenkürzel, Neuerungen, Über), das Zahnrad die
  Einstellungen. Die Einstellungen haben oben eine Leiste mit ihren Bereichen.

### Updates

- PDF Tool sucht bei jedem Start nach Updates und installiert ein gefundenes Update selbst, ohne Setup-Assistent.
  Danach startet es neu und öffnet die PDFs wieder, die offen waren. Mit ungespeicherten Änderungen wartet es.
- Abschaltbar unter Einstellungen → Updates → „Updates automatisch installieren“; dann bietet PDF Tool „Jetzt
  installieren“ an und zeigt die Neuerungen direkt darunter.

### Behoben

- PDF-Anhänge aus Outlook (klassisch und neu) öffnen sich zuverlässig, auch mit der Defender-Regel, die Outlook
  das Starten von Programmen verbietet, und auch wenn PDF Tool schon im Hintergrund läuft.
- In der Taskleiste steht „PDF Tool“ mit eigenem, auch klein scharfem Symbol statt „Python“.
- Vertragsübersichten: Datumsangaben als Text, als Excel-Zahl und verbundene Zellen werden richtig gelesen.
- Schneller beim Blättern großer PDFs, dazu viele kleinere Fehler aus den Betas.

### Update

Ein Update von 3.2 ersetzt die Programmdateien – dieses eine Mal noch mit dem Setup-Assistenten, ab dem nächsten
Update von selbst. Alle Einstellungen, Kundenakten, Vorlagen, Regelwerke und Sicherungen bleiben unverändert; vor
einem Update sichert PDF Tool die Daten automatisch.

Wer eine Beta von 4.0 nutzt (Kanal „Beta“), erhält 4.0.0 als Update; Daten, Einstellungen und der Kanal bleiben
erhalten.

### Installation

Das Setup `PDF-Tool-Setup-4.0.0.exe` enthält Python, Qt/PySide6, alle erforderlichen Pakete, die Texterkennung
Tesseract mit zehn Sprachen und die Laufzeit des optionalen KI-Assistenten – keine separate Installation nötig.
Das Sprachmodell ist nicht enthalten. Installation ohne Administratorrechte, Windows 10 (ab Version 1809) und
Windows 11 (64 Bit). Ein vorhandenes PDF Tool wird aktualisiert.

Die Datei `.sha256` enthält die Prüfsumme des Setups. Das Setup ist nicht signiert; beim ersten Start kann
Windows SmartScreen einen Hinweis zeigen („Weitere Informationen“ → „Trotzdem ausführen“).

**Alle Dateien werden lokal verarbeitet** – keine Cloud, keine Uploads.
